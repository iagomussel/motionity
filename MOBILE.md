# Motionity Mobile Controls

This document summarizes the mobile layout and touch gestures (<= 768px wide).

## Toolbar
- **Select/Move**: Enables object selection and dragging on the canvas.
- **Pan**: Enables one-finger panning of the canvas.
- **Library**: Opens the media library to add uploads, shapes, images, text, videos, or audio.
- **Undo / Redo**: Reverts or reapplies the last action.
- **Add Text**: Inserts a heading text at the canvas center.
- **Export**: Opens the download/export dialog.

## Canvas Gestures
- **Tap**: Select objects.
- **Drag (Select/Move)**: Move selected objects.
- **Drag (Pan mode)**: Pan the canvas.
- **Pinch (two fingers)**: Zoom the canvas in or out.

## Timeline
- **Drag keyframes**: Move keyframes horizontally on touch.
- **Drag seek bar**: Scrub time with touch.
- **Timeline handle**: Tap the handle to collapse/expand the timeline.

## Bottom Sheet
- **Layers tab**: Shows the layer list.
- **Properties tab**: Shows the selected object’s properties.
- **Handle**: Tap to open/close the sheet.
