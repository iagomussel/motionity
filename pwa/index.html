O VeloMotion é um editor de gráficos em movimento open-source focado em performance e usabilidade mobile. Edite no browser, tablet ou desktop.

Adaptive UI

Interface que se adapta perfeitamente ao mobile. Use gestos para editar seus keyframes.

Docker Ready

Instalação via Docker otimizada para WSL e ambientes de desenvolvimento locais.

High Performance

Engine de renderização leve que utiliza Web Workers para não travar sua interface.
